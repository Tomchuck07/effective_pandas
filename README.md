# Effective Pandas — working notes

My exercises from Matt Harrison's *Effective Pandas 2*: method chaining, `.assign`,
no in-place mutation, no row loops.

Method: read his solution, close the book, write it from memory, then correct against
his. The files are that process rather than polished code — where something got messy
before it got clean, both versions are kept.

Worked through chapters 1–5 (Series and DataFrames), then paused. The concepts are
applied to real data in
[thesis-liquidity-profitability-gpw](https://github.com/Tomchuck07/thesis-liquidity-profitability-gpw).
